# Jozz Portfolio Website

A complete, production-ready black & gold modern creative designer portfolio package.

## Included Files
- `index.html` - Home page
- `about.html` - About page
- `portfolio.html` - Portfolio gallery page
- `services.html` - Services page
- `contact.html` - Contact page (with email: Jozziofficial@gmail.com and phone: +2348023467011)
- `style.css` - Stylesheet with black & gold theme and animations
- `script.js` - JavaScript for mobile menu and form handling
- `assets/` - Folder for your images and media

## How to Upload & Deploy on GitHub Pages
1. Create a new repository on GitHub (named `your-username.github.io` or any repository name).
2. Extract this ZIP file.
3. Upload all extracted files directly to the root of your repository (drag and drop or via `git push`).
4. Go to your repository **Settings > Pages**, set the branch to `main` (or `master`), and save.
5. Your portfolio will be live in a few moments!
